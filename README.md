# 21 Grids Waffle Co. POS
PHP 8 + MariaDB point-of-sale system. Group One, 21-ITEN-01.

## Run it
1. Start Apache and MySQL in XAMPP.
2. In phpMyAdmin import database/01_GridsWaffle_POS_Schema_and_Data.sql, then database/04_GridsWaffle_POS_Sales_Oct19_to_Nov11.sql.
3. Put the project folder in htdocs and open http://localhost/<folder name>
